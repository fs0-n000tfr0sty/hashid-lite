# hashid-lite

guess what kind of hash you're looking at. no dependencies.

## usage

    python3 hashid.py 5f4dcc3b5aa765d61d8327deb882cf99
    MD5
    NTLM
    MD4

the first guess is the most common one. it's a guess, not a verdict.
